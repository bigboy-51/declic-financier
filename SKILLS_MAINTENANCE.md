## Update Checklist

### Before Every Update
- [ ] Document current state (screenshot trends, metrics, changes)
- [ ] Research what's changed since last update
- [ ] Identify 3-5 key improvements needed
- [ ] Update SKILL.md in the relevant folder
- [ ] Test locally via dashboard
- [ ] Commit with clear message: `chore: update [skill-name] - [brief reason]`
- [ ] Push to `claude/determined-goodall-8k4w4m` branch
- [ ] Test on Replit (git pull)

### Update Commit Message Format
```
chore: update [skill-name] - [change description]

- Updated [section] based on [source/reason]
- Added [new concept/feature]
- Removed [outdated information]

Last checked: YYYY-MM-DD
Next review: YYYY-MM-DD
```
