# Hooks — Psychological Frameworks

Master the universal principles that drive human behavior. These frameworks apply everywhere: sales, marketing, product design, negotiations, leadership, and personal development.

## Core Hooks Framework

### 1. The Hook Model (Nir Eyal)
**Trigger → Action → Variable Reward → Investment → Repeat**

Users form habits through this cycle:
- **Trigger** (external/internal): What prompts the user?
- **Action** (simplest behavior): Easiest path to reward
- **Reward** (variable): Unpredictable payoff drives engagement
- **Investment** (data/effort): User puts skin in the game → stronger commitment

*Application:* Every product, service, or message has a hook cycle. Map it. Optimize it.

### 2. The Persuasion Matrix (Cialdini)
Six universal principles guide decisions:
- **Reciprocity** — Give first, they give back
- **Commitment/Consistency** — Tiny yes leads to big yes
- **Social Proof** — If others are doing it, so should I
- **Authority** — Experts are trusted
- **Liking** — We say yes to people we like
- **Scarcity** — Limited supply = higher value

*Application:* Every persuasive message should leverage 2-3 of these principles stacked.

### 3. The Jobs to Be Done Framework (Clayton Christensen)
People don't buy products. They hire them to do a job.

- **Functional Job** — What task needs doing?
- **Emotional Job** — How should they feel?
- **Social Job** — Who do they want to be seen as?

*Application:* Stop selling features. Sell the job. "We don't sell drills, we sell holes in walls."

### 4. Loss Aversion (Kahneman & Tversky)
People feel pain of loss ~2.5x stronger than pleasure of gain.

- Show what they'll lose, not just what they'll gain
- Frame as preventing downside, not achieving upside
- "Don't miss out" > "You might gain"

*Application:* In messaging, loss framing converts better than gain framing. "Avoid [pain]" resonates more than "Achieve [gain]."

### 5. The Pygmalion Effect (Rosenthal)
People perform better when expected to. Your expectations shape reality.

- Tell people they're already successful → they become successful
- Position them as "the type of person who..." → they become that person
- Belief precedes behavior

*Application:* In marketing/leadership, suggest the identity before requesting the action.

### 6. Cognitive Biases Stack
Multiple biases compound:
- **Confirmation Bias** — Seek info that confirms beliefs
- **Availability Heuristic** — Recent/common = true
- **Anchoring** — First number sets the frame
- **Sunk Cost Fallacy** — Past investment drives future decisions

*Application:* Layer these biases in persuasive funnels. First number matters. Repeat it. They'll anchor to it.

### 7. The Customer Journey (Awareness → Consideration → Decision → Retention)
Different psychology at each stage:

- **Awareness** — Break through noise (novelty, emotion, contrast)
- **Consideration** — Build trust (social proof, authority, consistency)
- **Decision** — Reduce friction (scarcity, commitment, reciprocity)
- **Retention** — Create belonging (social, identity, investment)

*Application:* Different hooks work at different stages. Don't use decision-stage messaging in awareness.

### 8. The Endowment Effect
We value things more when we own them. Just showing we own it increases perceived value.

- Let people experience before buying (trial, demo, free sample)
- Once they "own" it mentally, they value it more
- Ownership (mental or physical) drives purchase

*Application:* Free trials, samples, and experiences sell better than cold pitches.

### 9. The Halo Effect
One positive trait makes us assume all traits are positive. One negative trait does the opposite.

- One powerful testimonial outweighs 10 mediocre ones
- One expert endorsement amplifies everything else
- First impression sets the filter

*Application:* Get one strong credibility anchor early. Everything else gets filtered through it.

### 10. The Power of Defaults (Thaler)
People don't choose. They stick with what's already selected.

- Default = 99% adoption
- Opt-in = 20% adoption
- Opt-out = 98% adoption

*Application:* Make the desired behavior the path of least resistance.

## Stacking Framework

The most powerful persuasive sequences stack 3-4 hooks:

**Conversion Stack Example:**
1. **Anchor** (anchoring bias) — "The market price is $997"
2. **Social Proof** (principle) — "10,000+ customers"
3. **Scarcity** (principle) — "Only 50 spots left"
4. **Ownership** (endowment) — "Try free for 7 days"
5. **Commitment** (principle) — "One-click checkout"

Each hook layer increases conversion. Don't use all 10. Use 3-4 in sequence.

## Context Matters

These hooks work differently across contexts:
- **B2C Sales** — Emotional/social proof hooks dominate
- **B2B Sales** — Authority/reciprocity hooks dominate
- **Content** — Curiosity gaps + social proof
- **Products** — Jobs + habit loops
- **Leadership** — Expectations (Pygmalion) + commitment

Adapt the hook to the context.

---

## Warning

Hooks are neutral. They can persuade ethically (genuine value → aligned hook) or manipulatively (no value → deceptive hook).

Use these to:
- ✅ Communicate real value more effectively
- ✅ Build genuine loyalty
- ✅ Create ethical persuasive systems

Don't use these to:
- ❌ Manipulate without value
- ❌ Deceive about benefits
- ❌ Exploit vulnerabilities

The best persuasion is honest persuasion. Alignment is everything.

## Quick Reference

| Hook | Use When | Caution |
|------|----------|---------|
| Trigger → Action → Reward → Investment | Building habit-forming products | Risk of addiction cycles |
| Reciprocity | Giving value first | Feels transactional if not genuine |
| Social Proof | Uncertain buyers | Can amplify bad reputations too |
| Scarcity | High-ticket items | Perceived scarcity loses trust if exposed |
| Loss Aversion | Risk-averse audience | Can feel fear-based |
| Endowment Effect | Before deciding | Works best with genuine trial experiences |
| Jobs to Be Done | Any product/service | Requires deep customer research |
| Authority | Complex decisions | Fake experts destroy credibility |
